# 🛒 Full-Stack E-Commerce Website (In Progress 🚀)

A full-stack e-commerce web application built using the **MERN Stack** (MongoDB, Express.js, React, Node.js). Currently, the project features secure user authentication, personalized shopping carts, real-time search functionality, and secure payment gateway integration.

---

🚀 Live Demo

Live Website: https://e-commerce-frontend-98ck.onrender.com/

## ✨ Key Features (Implemented So Far)

- **Secure Authentication:** User login and logout system powered securely by **JWT (JSON Web Tokens)**.
- **Personalized Shopping Cart:** - Dynamic and user-specific cart. Each logged-in user can only view, manage, and interact with their own added products.
  - Full CRUD in cart: Easily **add**, **delete**, and dynamically **increase/decrease product quantity** (plus/minus functionality) with instant updates.
- **Real-Time Dynamic Search:** As you type in the search bar, matching product names instantly display in a dynamic dropdown list directly below the search box.
- **Payment Gateway Integration:** Fully functional test payments integrated using **Razorpay API**.

---

## 🛠️ Tech Stack Used

**Frontend:**
- **React.js** (Functional Components, Hooks, Context API/State Management)
- **HTML5 & CSS3** (Responsive Layouts)
- **JavaScript (ES6+)**

**Backend & Database:**
- **Node.js** & **Express.js** (RESTful API Development & Routing)
- **MongoDB** (Database for storing products, users, and user-specific cart data)
- **Mongoose** (Object Data Modeling)

**Authentication & Security:**
- **JWT (JSON Web Tokens)** & **Bcrypt** (Password Hashing)

**Payment Integration:**
- **Razorpay SDK**
